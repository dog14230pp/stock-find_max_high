# 實驗前先說明，等 OK 再做

使用者常跟不上太快、太多的內容，也曾因為 Claude 自行加條件而誤會結果。
所以每次實驗前都照下面的步驟，**沒有得到「OK / 可以 / 開始」之類的明確同意前，不寫程式、不跑、不改 registry**。

## 步驟

1. **一句話說要做什麼**：例如「在 S8 的點上，再檢查那一分鐘是不是前買後賣」。
2. **列出用到的條件**：每個條件一行，標明來源（使用者指定 / 沿用哪個策略）。
   - 不要自行帶入其他策略的條件；想加的話，另外列出來問。
3. **用圖解說明**：用文字圖（等寬字的時間軸、表格、小例子）示範一個具體情況，例如：
   ```
   一分鐘裡有成交的秒：  5   18   33   50
   切法 2：            [5, 18] | [33, 50]
                       前段（看買）  後段（看賣）
   ```
   - 用實際數字舉例，算一次給使用者看。
4. **說明要決定的細節**：門檻、窗口、例外情況，各自給建議值和理由；一次不要超過 3～4 個。
5. **說明輸出**：會產生什麼表格 / 圖 / 網頁、怎麼判斷好壞（Hit、多找的點、虧損）。
6. **停下來問**：「這樣可以開始嗎？」然後等使用者回覆。

## 寫法

- 一次講一件事，句子短；少用術語，用到就順便白話解釋。
- 使用者說看不懂時，換一個更具體的例子重講，不要加更多公式。
- 使用者確認後才實作；實作完回報時，也先講結論，再列數字。
